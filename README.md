# 1942 ✈️

추억의 오락실 세로 슈팅 「1942」 스타일의 혼자 하기. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 `index.html` + `logic.js`(규칙) + `game.js`(화면·입력·소리)로 돌아갑니다. 그림은 모두 코드로 그렸고(원작 그림·소리는 쓰지 않았다) 바다와 섬은 스크롤하면서 계속 만들어진다.

- **내 비행기**: 방향키/WASD 로 이동(화면 밖으로는 못 나감), 스페이스(Z·J)를 **누르고 있으면** 쌍발 총알(초당 약 6.5번, 화면에 14발까지). 폰은 왼쪽 아날로그 패드(밀수록 빨라짐)와 오른쪽 발사 버튼
- **회전(루프)**: X(K·Shift) 또는 파란 버튼. 1초 동안 어떤 총알과 적에도 안 맞고 비행기가 커졌다 돌아온다. 그동안 총은 못 쏜다. 한 스테이지에 3번, 새 스테이지가 되면 다시 3번
- **적**: 초록 비행기가 줄지어(직선·대각선·한 바퀴 돌며·아래에서) 들어오고 가끔 나를 조준해 쏜다. 스테이지가 오를수록 빠르고 많이, 자주 쏜다. 중형 폭격기(여러 번 맞아야 하고 3갈래로 쏨, 800점)가 스테이지마다 나온다. 비행기에 부딪히면 나도 부서진다
- **POW**: **빨간 비행기 다섯 대를 한 대도 놓치지 않고 모두** 맞히면 POW 가 떨어진다(먹으면 500점). 종류: G 총알 4발 · W 호위기 2대 · B 화면의 작은 비행기와 적 총알 모두 없앰(폭격기·보스는 그대로) · R 회전 +1 · 1UP 목숨. 맞으면 G·W 는 사라진다
- **보스**: 스테이지 52초가 되면 나온다(체력 `80 + 15 x 스테이지`, 좌우로 움직이며 5갈래 조준탄과 12갈래 원형탄). 쓰러뜨리면 5000점 + **명중률(%) x 50점**, 다음 스테이지
- **목숨**: 4개, 1만 5천 점에서 하나, 이후 6만 점마다 하나. 맞으면 1.5초 뒤 같은 자리에서 2.5초 동안 깜빡이며 안전하게 다시 나온다
- **일시정지**: 창을 벗어나거나 탭이 가려지면 저절로 멈춘다 (P 로도). 최고 점수는 `game1942Best`

원작과 다르게 정했거나 기억에 의존한 점: 편대 모양과 시간표, 점수, 속도, 보스(원작은 스테이지마다 다른 대형 폭격기), 명중률 보너스 계산, POW 종류와 확률, 스테이지 수(원작은 32까지, 여기는 계속 이어진다).

시험은 `node --test`(`test/logic.test.js`): 비행 경로(루프가 제자리로 돌아오는지) · 시간표(정렬, 빨간 비행기 5대 묶음, 폭격기) · 이동과 화면 안 제한 · 발사 속도와 한도 · G 와 W 총알 수 · 격추 점수 · 폭격기 · 빨간 비행기 5대와 POW · POW 효과 · 회전 · 맞으면 죽고 돌아옴 · 게임 끝 · 조준탄 · 보스와 명중률 보너스와 다음 스테이지 · 목숨 보너스 · 무작위 플레이.

튜토리얼 신호(`arcade/tutorials.js`): `move` · `fire`(내가 쏨) · `kill`(격추) · `roll`(회전) · `pickup`(POW).

- **난이도 조금 완화**(난이도 점검 뒤): 시작 목숨 3→4, 추가 목숨 2만·8만→1만 5천·6만 점, 단계마다 적 비행기 속도 +7%(최대 1.6배)→+5%(최대 1.4배), 적 탄 속도 상한 낮춤(일반 135→115, 폭격기 무제한→105, 보스 150→125), 일반 적이 쏠 확률 상한 90%→75%
